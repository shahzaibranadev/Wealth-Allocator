# 💎 Wealth Allocator

**Author:** shahzaibRana

Smart wealth allocation for strategic portfolio planning.
Define your income, distribute across diverse assets, and visualize your financial growth journey.



## 🚀 Features

- **Income Configuration**
  Enter your monthly net income and select your preferred currency.

- **Asset Distribution**
  Allocate your wealth across multiple asset classes:
  - 📈 Stocks  
  - 🥇 Gold  
  - 📊 ETFs  
  - 🏢 REITs  
  - 💵 Government Bonds  
  - 🏦 Time Deposits  
  - ₿ Cryptocurrency  
  - 🛢 Commodities  

- **Portfolio Summary**
  Get a detailed breakdown of your distribution and visualize your monthly allocation.

- **Modern UI/UX**  
  Sleek dark theme with elegant animations.

## 🛠️ Tech Stack

- **Frontend:** React + JSX  
- **Styling:** Tailwind CSS  
- **Animations:** Framer Motion  

## 📦 Installation & Setup

Clone the repository:
```
git clone https://github.com/shahzaibRana/wealth-allocator.git
cd wealth-allocator
```
Install dependencies:
```
npm install
```
Run the development server:
```
npm run dev
```
Open http://localhost:5173 in your browser.
